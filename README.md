# TH1 - GPIO Interrupt, Debounce, ADC Filter
# Bài 1 - Interrupt
Sử dụng ngắt ngoài với nút nhấn.
LED phản hồi khi xảy ra sự kiện ngắt.
# Bài 2 - Debounce
Chống dội nút nhấn bằng millis().
Ngưỡng debounce được chọn là 50ms.
# Bài 3 - ADC Filter
Đọc giá trị ADC từ biến trở.
Áp dụng bộ lọc trung bình trượt.
Điều khiển độ sáng LED bằng PWM.
